Raspberry Pi Projects

Abstract

- Goal: Use the RGB lights on the Raspberry PI to create various displays
- Created a binary clock using a pipeline to access real-time, and an algorithm to calculate the time into binary
- Used the lever on the Raspberry Pi and remainders in loops to create the illusion of a scrolling initial across the screen
- Used registers in Assembly Language to create various patterns on the Raspberry Pi


Assembly Language Projects


The goal was to create various patterns on the Raspberry Pi using registers in Assembly Language. The first pattern was to cover the whole screen with a solid color. The next pattern was to draw a red X using a looping function. The final pattern was to create our initials on the screen.

The goal was to have a dot move across the screen using input from the joystick. The dot was to react to both tapping and holding joystick. The dot is supposed to stop when it reaches the end of the screen.
