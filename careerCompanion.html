Career Companion

Visit Career Companion Website!

- Goal: Create an AI-Assisted Job Search Website that updates questions via user input
- Uses an AI API to generate potential career opportunities based on questionaire results
- The website has two questionnaires: a simple questionnaire with yes or no questions, and a detailed questionnaire where options are rated one to five, with ability to write comments
- Implemented a question rater that tracks answered questions, improving the questions based on user feedback
- Implemented question generation into the detailed questionnaire
- Stored the user’s answers within the website, ensuring a personalized experience
- Trained the AI model to act as career assistant to provide thoughtful career options
